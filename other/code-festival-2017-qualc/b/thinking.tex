\subsection*{つまずき}
無し。「$\exists$（どれか 1 つが偶数）」を直接数えずに、余事象の「$\forall$（全部奇数）」に切り替えたのが効いた。

\subsection*{正しい考え方}
\begin{enumerate}
  \item 条件 $|x_i - y_i| \leq 1$ を $-1 \leq x_i - y_i \leq 1$、つまり $y_i = x_i + \lbrace 0, \pm 1 \rbrace$ の 3 通りと書き直す。
  \item 「積が偶数 $\iff$ どれかの項が偶数」なので、余事象「全部奇数」を数える。
  \item 全体は各項 3 通りで $3^n$。全部奇数になるのは、$A_i$ が偶数の項（個数 $m$）だけ 2 通り（$\pm 1$）、奇数の項は 1 通り（そのまま）なので $2^m$。
  \item 答えは $3^n - 2^m$。サンプルで検算: \verb|2 / 2 3| は $m=1$ で $3^2 - 2^1 = 7$、\verb|3 / 3 3 3| は $m=0$ で $3^3 - 2^0 = 26$。
\end{enumerate}

\subsection*{次に活かすこと}
\begin{itemize}
  \item 「少なくとも 1 つ〜」を数える問題は、まず余事象「全部〜でない」が積で書けないかを見る。
  \item 検算で $m = 0$ の端（全部奇数）も確かめていたのはよかった。
\end{itemize}
