## メモで考えたこと

1. 長さ N の A を K 回つなげた B（長さ K·N）の転倒数 t を 10⁹+7 で割った余り、と書き直した。
   例: A = 1, 3, 2、K = 2 なら B = 1, 3, 2, 1, 3, 2。
2. t = count((i, j) : 0 ≤ i < j ≤ K·N−1 かつ B_i > B_j) と式にした。
3. サンプル `2 2 / 2 1`（B = 2, 1, 2, 1）で、大きい値から小さい値へ弧を描いて転倒ペアを数えた。
   同じコピーの中のペアと、コピーをまたぐペアを描き分けている。

## つまずき

無し。弧の図で「同じコピー内」と「コピー間」を分けて見たのがそのまま解法になった。

## 正しい考え方

- 同じコピー内の転倒: A の中で i < j かつ A_i > A_j の数を x とすると、K 個のコピーそれぞれに x 個 → K·x。
- コピー間（前のコピーの A_i と後ろのコピーの A_j）: 位置に関係なく A_i > A_j の組が転倒になる。
  そういう (i, j) の数は x + y（y は i < j かつ A_i < A_j の数）、コピーの組は K(K−1)/2。
- 合計 K·x + (x + y)·K(K−1)/2 = x·K(K+1)/2 + y·K(K−1)/2。提出コードはこの形。
