## 1. 問題

スイッチが N 個（1..N、それぞれ ON/OFF）、電球が M 個（1..M）ある。

- 電球 i は k_i 個のスイッチ s_{i,1}, …, s_{i,k_i} につながっている。
- **電球 i が点灯する条件**: つながっているスイッチのうち **ON のものの個数 ≡ p_i (mod 2)**。
  - p_i = 0 なら「ON の本数が偶数」、p_i = 1 なら「ON の本数が奇数」。

**求めるもの**: 全 M 個の電球が点灯するような、スイッチの ON/OFF の組み合わせの総数。

- 制約: **1 ≤ N, M ≤ 10**、1 ≤ k_i ≤ N、p_i ∈ {0, 1}
- 入力形式:
  ```
  N M
  k_1 s_11 … s_1k_1
  ⋮
  k_M s_M1 … s_Mk_M
  p_1 p_2 … p_M
  ```

---

## 2. 考察の起点 — 制約が「全探索していい」と言っている

この問題で最初に見るべきは **N ≤ 10** という異様に小さい制約。
スイッチ 1 個につき ON/OFF の 2 通りなので、組み合わせは全部で

  **2^N ≤ 2^10 = 1024 通り**

しかない。1024 通りを全部作って、それぞれについて「M 個の電球が全部点くか」を
確かめても、判定 1 回のコストは Σk_i ≤ M·N ≤ 100 程度。合計でも

  1024 × 100 ≈ 10^5 回

の演算で済む（AtCoder の 2 秒制限に対して桁違いに余裕）。

> **典型パターン**: 「N ≤ 20 くらい」＋「各要素が 2 択」＝ **bit 全探索を疑う**。
> 賢い式変形を探す前に、まず制約から許される計算量を見積もるのが速い。

---

## 3. 解法 — bit 全探索

### 3.1 ON/OFF の組み合わせを整数 1 個で表す

N 個の ON/OFF は、長さ N の 0/1 列。これを **整数 `bit` の 2 進表現**とみなす。

- `bit` の第 v ビット（0-indexed）が 1 ⇔ **スイッチ v が ON**
- `bit` を `0` から `2^N - 1` まで動かす ⇔ **全パターンをちょうど 1 回ずつ列挙**

例（N = 3）:

| bit | 2進 | sw2 | sw1 | sw0 |
|-----|-----|-----|-----|-----|
| 0 | 000 | OFF | OFF | OFF |
| 1 | 001 | OFF | OFF | **ON** |
| 2 | 010 | OFF | **ON** | OFF |
| … | … | | | |
| 7 | 111 | **ON** | **ON** | **ON** |

「スイッチ v が ON か？」は `bit & (1 << v)` が非 0 かどうかで判定できる。

### 3.2 各パターンを判定する

`bit` を 1 つ固定したら、電球 i ごとに

1. `s[i]` に入っているスイッチを見て、ON の本数 `con` を数える
2. `con % 2 == p[i]` なら電球 i は点灯、違えばこのパターンは失格

M 個すべてが点灯したパターンだけを数え上げれば、それが答え。

### 3.3 計算量

- 外側ループ: 2^N ≤ 1024
- 内側: Σk_i ≤ M·N ≤ 100

合計 **O(2^N · Σk_i) ≤ 約 10^5**。余裕で間に合う。

## 4. 擬似コード

```
読み込み: N, M
読み込み: 各電球 i について k_i と接続スイッチ列 s[i]（0-indexed に直す）
読み込み: p[0..M-1]

res = 0
for bit in 0 .. 2^N - 1:
    ok = true
    for i in 0 .. M-1:
        con = (s[i] のうち bit で ON になっているスイッチの本数)
        if con % 2 != p[i]: ok = false
    if ok: res += 1
print(res)
```

---

## 5. 実装 (C++) の要点

実物は `main.cpp`。押さえるべきは 3 か所だけ。

```cpp
int a; cin >> a; --a;              // (1) 1-indexed → 0-indexed
...
for (int bit = 0; bit < (1<<N); ++bit) {   // (2) 2^N 通りの列挙
    ...
        if (bit & (1<<v)) ++con;           // (3) スイッチ v の ON 判定
```

- **(1) `--a` を忘れない**。入力のスイッチ番号は 1 始まり。0 始まりに直しておくと、
  そのまま `1 << v` のビット位置として使える。忘れると「スイッチ N」が
  第 N ビット（＝ `bit < (1<<N)` の範囲外）を指してしまい、常に OFF 扱いになる。
- **(2) `1<<N` が全パターン数**。`<=` ではなく `<` であることに注意（`0` 〜 `2^N - 1`）。
- **(3) `bit & (1<<v)`** は 0 か非 0 を返す（1 とは限らない）。真偽値として使うのが安全。

補足:

- 電球が 1 つでも不適なら即 `break` してよいが、M ≤ 10 なので最後まで回しても速度は変わらない。
- `res` は最大でも 1024 なので `int` で足りる。数え上げは既定で `long long` にしておくと、
  制約が大きい問題に同じ書き方を持ち込んだときに事故らない。

## 6. サンプルで確認

### サンプル 1（答え: 1）

```
2 2
2 1 2      ← 電球1 は スイッチ1,2 に接続
1 2        ← 電球2 は スイッチ2 に接続
0 1        ← p = (0, 1) : 電球1 は偶数本 ON、電球2 は奇数本 ON で点灯
```

4 通りを全部書き出すと:

| bit | sw1 | sw2 | 電球1 の ON 本数 | ≡ p₁=0? | 電球2 の ON 本数 | ≡ p₂=1? | 採用 |
|-----|-----|-----|------------------|---------|------------------|---------|------|
| 00 | OFF | OFF | 0 | ✓ (偶) | 0 | ✗ (偶) | — |
| 01 | ON | OFF | 1 | ✗ | 0 | ✗ | — |
| 10 | OFF | ON | 1 | ✗ | 1 | ✓ | — |
| 11 | ON | ON | 2 | ✓ | 1 | ✓ | **✓** |

→ 出力 **1**。

### サンプル 2（答え: 0）

電球2（スイッチ1 のみ・偶数）が「スイッチ1 は OFF」を強制し、
電球3（スイッチ2 のみ・奇数）が「スイッチ2 は ON」を強制する。
すると電球1（スイッチ1,2・偶数）は ON 本数 1 で点かない。→ 該当パターンなしで **0**。

### サンプル 3（答え: 8）

```
5 2
3 1 2 5
2 2 3
1 0
```

条件は 2 本だけ:

- 電球1: スイッチ 1, 2, 5 のうち ON が **奇数**本
- 電球2: スイッチ 2, 3 のうち ON が **偶数**本

**スイッチ 4 はどの電球にもつながっていない**ので、ON/OFF どちらでも自由（×2）。
残りも条件 2 本に対して自由度が 3 つ残るので 2³ = **8**。実行結果も 8 で一致。

## 7. 一段深い見方 — これは GF(2) 上の連立一次方程式

スイッチ v の状態を x_v ∈ {0, 1} と置くと、電球 i の条件はそのまま

  **x_{s_{i,1}} ⊕ x_{s_{i,2}} ⊕ … ⊕ x_{s_{i,k_i}} = p_i**  （⊕ は XOR = mod 2 の足し算）

つまりこの問題は **mod 2 の連立一次方程式の解の個数を数えよ**、という問題。
線形代数の定理から、解の個数は

- 方程式が矛盾していれば **0**
- 矛盾がなければ **2^(N − rank)**（rank は係数行列の GF(2) 上のランク）

サンプルで確かめると:

| サンプル | 式の本数 | rank | 解の個数 |
|----------|----------|------|----------|
| 1 | 2 | 2 | 2^(2−2) = **1** ✓ |
| 2 | 3 | 2（かつ矛盾あり） | **0** ✓ |
| 3 | 2 | 2 | 2^(5−2) = **8** ✓ |

**この問題では N ≤ 10 なので全探索で十分**だが、**N が 1000 や 10^5 になったら
掃き出し法（Gauss-Jordan over GF(2)、bitset で高速化）に切り替える**必要がある。
「XOR の条件を満たす組み合わせを数える」系はこの構造を持つことが多いので、
全探索が通らないときの次の一手として覚えておく。

## 8. 覚えておくこと

1. **制約を先に読む**。N ≤ 10〜20 で各要素が 2 択なら bit 全探索。
2. **bit 全探索の型**: `for (int bit = 0; bit < (1<<N); ++bit)` ＋ `bit & (1<<v)`。
3. **入力の 1-indexed は読み込み時に `--a` で潰す**。ビット位置と番号を一致させる。
4. **XOR 条件の数え上げ＝ GF(2) の連立方程式**。答えは 0 か 2^(N−rank)。
   全探索が間に合わない規模ならこちらへ。
