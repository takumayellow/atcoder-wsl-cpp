\subsection*{メモで考えたこと}
メモでは、N 個のスイッチ・M 個の電球、電球 $i$ は $k_i$ 個のスイッチ $s_{i1}, \dots, s_{ik_i}$ につながる、と整理し、
点灯条件を「$(s_{i1}, \dots, s_{ik_i}$ のうち on の個数$) \bmod 2 = p_i$」と式にした。
入力形式を書き写し、サンプル \verb|2 2 / 2 1 2 / 1 2 / 0 1| を「電球 1 はスイッチ 1, 2 のうち偶数個 on、電球 2 はスイッチ 2 が奇数個 on」と読んで、
条件を満たす組を手で探した。メモは問題の読み取りまでで、解法（全探索）はメモに書いていない。

\subsection*{つまずき}
\begin{itemize}
  \item \textbf{CE}: C++ のコードを言語 Python のまま提出した（同じ分に C++23 で出し直して AC）。
  \item 解法の根拠（$N \leq 10$ だから $2^N \leq 1024$ 通りを全部試せる）がメモに無い。
\end{itemize}

\subsection*{正しい考え方}
スイッチの on/off を $N$ ビットの整数 \verb|bit| で表し、$\mathtt{bit} = 0, \dots, 2^N-1$ を全部試す。
各電球について on のスイッチ数の偶奇が $p_i$ と一致するかを見る。$O(2^N \cdot \sum k_i)$。
詳しくは \texttt{explanation.md}。

サンプル 1（電球 1 = スイッチ \{1,2\} が偶数個、電球 2 = スイッチ \{2\} が奇数個）の 4 通りを並べると次のとおり。
