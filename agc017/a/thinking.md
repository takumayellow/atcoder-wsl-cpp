## メモで考えたこと

1. 袋を並べて描き、最初に「A_i % 2 = P」と書いて消した（1 袋ずつの偶奇では決まらない）。
2. 選ぶかどうかを c_k ∈ {0, 1} とし、**(Σ c_k A_k) % 2 = P** となる c の数え上げ、と定式化した。
3. 素直に全部試すと 2ᴺ 通りで、N = 50 だと 2⁵⁰ なので無理（メモに「2⁵⁰ ✕」）。
4. サンプル `1 1 / 50` → 0、`3 0 / 1 1 1` などを見て場合分け。
   - 全部の A_i が偶数: 和は必ず偶数。P = 0 なら 2ᴺ、P = 1 なら 0。
   - 奇数の A_k がある: k 番目以外の N−1 袋の選び方は 2ᴺ⁻¹。その和 S が奇数なら k を選べば偶数・選ばなければ奇数、S が偶数なら逆。
     どちらの P に対しても **k の選び方がちょうど 1 通りに決まる** ので、答えは 2ᴺ⁻¹。

## つまずき

- メモでは 1 つ目の場合を「∀A_i = odd」と書いているが、結論（P = 0 なら 2ᴺ、P = 1 なら 0）が成り立つのは **全部偶数** のとき。
  直後の行が「A_i has odd（∃k, A_k = odd）」なので、書き間違い。コードは `a[i] % 2 == 1` の有無で分けていて正しい。
- 最初の「A_i % 2 = P」は、和の偶奇を 1 項ずつの偶奇と混同した一歩目。すぐ消して Σ の形に直せている。

## 正しい考え方

奇数の袋が 1 つでもあれば、それを「偶奇を調整する袋」として取っておくと、残りの選び方と 1 対 1 に対応する。
よって答えは奇数の袋があれば 2ᴺ⁻¹、無ければ P = 0 のとき 2ᴺ、P = 1 のとき 0。
