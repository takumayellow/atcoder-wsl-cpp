\subsection*{つまずき}
\begin{itemize}
  \item \textbf{TLE}: $b \leq 10^{18}$ を見る前に、1 つずつ数えるループを書き始めた。
  \item \textbf{WA}: \verb|b//x - a//x + 1| を提出した。$+1$ が正しいのは $a$ が $x$ で割り切れるときだけ。
    検算した 3 例のうち 2 例（\texttt{4 8 2}, \texttt{0 5 1}）がたまたま割り切れるケースで、
    3 例目（\texttt{1 100 3}）で「$+1$?」と迷ったのに確かめずに出した。
\end{itemize}

\subsection*{正しい考え方}
$0$ 以上 $n$ 以下の $x$ の倍数の個数を $g(n) = \lfloor n/x \rfloor + 1$ とおくと、
$[a,b]$ の個数は $g(b) - g(a-1) = \lfloor b/x \rfloor - \lfloor (a-1)/x \rfloor$。
$a=4,\ b=8,\ x=2$ の数直線で見ると次のとおり。

\begin{center}
\begin{tikzpicture}[x=1.15cm]
  % 例: a=4, b=8, x=2
  \draw[-{Stealth}] (-1.6,0) -- (9.8,0);
  \foreach \i in {-1,...,9} {\draw (\i,0.1) -- (\i,-0.1) node[below=2pt] {\small $\i$};}
  \foreach \i in {0,2,4,6,8} {\fill (\i,0) circle (2.6pt);}
  \draw[redpen,line width=1.2pt] (4,0.45) -- (8,0.45);
  \node[redpen,above] at (6,0.45) {\small $[a,b]=[4,8]$ の倍数 4, 6, 8};
  \draw[decorate,decoration={brace,amplitude=5pt,mirror}] (-0.2,-0.75) -- (8.2,-0.75)
    node[midway,below=6pt] {\small $g(8) = \lfloor 8/2 \rfloor + 1 = 5$};
  \draw[decorate,decoration={brace,amplitude=5pt,mirror}] (-0.2,-1.75) -- (3.2,-1.75)
    node[midway,below=6pt] {\small $g(a-1) = g(3) = 2$};
\end{tikzpicture}
\end{center}

$a=0$ のときは $\lfloor -1/x \rfloor = -1$（Python の \verb|//| は負の方向へ切り捨て）なので、そのまま $0$ も数えられる。
C++ の \verb|/| は $0$ 方向へ切り捨てるので \verb|(a-1)/x| が $0$ になり、$a=0$ で 1 足りない。
C++ では \verb|b/x - (a == 0 ? -1 : (a-1)/x)| のように分ける。

\subsection*{次に活かすこと}
\begin{itemize}
  \item 区間 $[a,b]$ の個数は、累積の差 $g(b) - g(a-1)$ で書く。端の $\pm 1$ を場合分けで直さない。
  \item 検算のサンプルに「端が条件を満たさないケース」を 1 つ入れる。迷った例は出す前に手で数える。
  \item 書き始める前に制約を見る。
\end{itemize}
